The problem

Agents need useful context, clear access boundaries and a way to carry out computer tasks. My contributions span the ingestion, memory and execution paths that support those capabilities.

My contributions

I added the permission layer and heavily modified ingestion to support agent memory and enforce strict permissions.

I integrated and substantially modified Graphiti to develop company and personal memory graphs for agents to retrieve from.

I added Linux VM computer use to the agentic loop and updated the main loop to invoke desk sessions for computer tasks.

I implemented credential management and agentic logins, including cookie and Chrome profile management.

Persistent logins

Challenge. The hardest part was figuring out how to keep logins persistent with minimal resources.

Decision. I gave the agent its own computer, enabling a persistent IP, browser profiles and transferable cookies.

Tradeoff. This was a fairly expensive option, but it also expanded the agent’s capabilities and enabled things that were not possible before.

Takeaway. The tradeoff was higher infrastructure cost for persistent sessions and broader capabilities.

Deployment

I ran Contxt locally with Docker first and personally deployed it to Azure, where it is now hosted. Deployment experience is scoped to pilots and demos with test or pilot users.

Scope & outcomes

These are implemented contributions in an actively developed product. No adoption, reliability or performance metrics are claimed here.

The broader product contains additional capabilities and inherited components; this page describes only my confirmed work.
